# Decoding the Movie Personality

Applied Data Science project (Python): predicting user ratings with TMDB production metadata and audience persona clustering.

## Setup

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

Then open notebooks under `notebooks/`.
